# Flight Delay Predictor ✈️📊

Ein Data-Analyst-Portfolio-Projekt zur Analyse von Flugverspätungen und einer interaktiven Web-App für Vorhersagen.

## 🛠️ Projektübersicht
Dieses Projekt untersucht Flugdaten, um Muster bei Verspätungen zu erkennen und mithilfe von Machine Learning (Random Forest) Vorhersagen über mögliche Flugverspätungen zu treffen.

- **`Flight_delay_project.ipynb`**: Das Jupyter Notebook mit der gesamten explorativen Datenanalyse (EDA), Feature Engineering, Modelltraining und Evaluation.
- **`flt_delay_app.py`**: Eine interaktive Streamlit-App, mit der Nutzer über ein einfaches Interface Flugdetails eingeben können, um das Verspätungsrisiko live zu berechnen.
